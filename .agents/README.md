# Runtime-Neutral Agent Assets

This folder contains agent-readable assets that are not tied to one product.

- `skills/pgsa/SKILL.md` is the runtime-neutral PGSA skill.
- Tool-specific bundles live under root `skills/`.
- Adapter notes live under `adapters/`.

The same boundary applies everywhere: PGSA is a repo-local artifact protocol,
not a model-internal feature and not a product benchmark.
