# PGSA Start Session

Use this command at the beginning of a Claude Code-style session.

1. Read `pgsa/project.yaml`.
2. Read `pgsa/sessions.yaml`.
3. Select the active session.
4. Read `pgsa/harness/<session>.md`.
5. Read relevant contracts, summaries, open merge proposals, reviews, and
   integration state.
6. State which PGSA artifacts may need updates before editing code.
