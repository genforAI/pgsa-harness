# Working Context

PGSA Harness Core v0.1 is in the experimental harness-release phase.

The goal is to make PGSA usable as a repo-local project-coherence layer for coding-agent workflows.

## Current release focus

- Harness-first GitHub repo layout.
- Codex workflow adapter and runtime-neutral skill surface.
- Claude Code and Grok Build scaffold adapters.
- Generic CLI fallback.
- Lifecycle supervisor documentation.
- Example project and smoke tests.

## Current evidence boundary

Current evidence is local generated git-worktree architecture-protocol evidence only. It is not a Codex / Claude Code / Grok product benchmark.
