# PGSA Command Prompts

This folder contains command-style prompts for coding-agent workflows.

They are not executable shell commands. They are small, reusable instructions
that an agent can run as a slash-command-style workflow:

- start a session;
- update a contract;
- propose a semantic merge;
- run a review gate;
- check integration readiness;
- generate a drift report.

The source of truth remains the repo-local `pgsa/` artifact layer.
