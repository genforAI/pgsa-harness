# PGSA Review Gate Command

Use this command when a change affects another session, UI consumer, docs,
security, permissions, or final integration readiness.

1. Identify the affected session or review owner.
2. Read `pgsa/harness/<session>.md`.
3. Read relevant contracts and session summaries.
4. Update or create the relevant file under `pgsa/reviews/`.
5. Mark blocking issues explicitly.
6. If review cannot pass, create or update a merge proposal.
7. Append a ledger event.
