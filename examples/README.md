# Examples

This folder contains small PGSA artifact examples.

`teamtask-projectboard/` is a runnable, validation-clean example with a complete
repo-local `pgsa/` artifact layer. Use it as the primary example for new users.

Some generated or report-package examples elsewhere in the PGSA workspace are
artifact demonstrations. They are useful for review, but this folder should stay
focused on examples that can be validated from the released harness.
