# NLA Cognitive Audit Adapter Spec

Purpose: attach NLA/ALM-style interpretability observations to high-risk PGSA decisions.

Rules:

1. Label outputs as hypotheses.
2. Never let cognitive hypotheses override hard runtime or test evidence.
3. Link each note to a session, task, model, activation range, and corroborating or contradicting evidence.
4. Use only in high-risk or anomalous sessions by default.
