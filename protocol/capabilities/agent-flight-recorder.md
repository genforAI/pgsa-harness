# Agent Flight Recorder

The Agent Flight Recorder turns an agent run into evidence. It records commands, files, permissions, diffs, tests, versions, evaluator notes, and decisions in a form that can be linked to the coherence ledger.

Hard evidence belongs in runtime/tool logs. PGSA stores summarized, repo-local, inspectable evidence references.

Reference artifact:

- `pgsa/evidence/runtime_evidence.jsonl`
- `pgsa/ledger/coherence_ledger.jsonl`
