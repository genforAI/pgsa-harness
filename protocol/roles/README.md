# Roles

PGSA roles are project-defined.

The examples in this folder are starter role definitions. They are not required
role names and should be adapted to the target repository.

Use roles to define:

- ownership scope;
- artifacts the role must read and update;
- affected contracts;
- review and integration responsibilities;
- optional external bindings to project-specific agent runners.

A session is a project-specific instance of a role.

See:

- `protocol/templates/role.template.yaml`
- `protocol/templates/session_binding.template.yaml`
