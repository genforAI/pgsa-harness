# Claim Boundary

Allowed:

- PGSA Harness Core is a repo-local project-coherence layer for coding-agent
  workflows.
- It can wrap Codex-style, Claude Code-style, Grok Build-style, and generic CLI
  workflows through repo-local artifacts.
- Current evidence is local generated git-worktree architecture-protocol
  evidence only.

Do not claim:

- PGSA beats Codex, Claude Code, Grok Build, OpenAI, Anthropic, or hosted
  products.
- PGSA improves Codex by X%.
- PGSA is inside Codex.
- PGSA modifies Codex, Claude Code, or Grok internals.
- PGSA is production validated.
- Local generated evidence is a product benchmark.
