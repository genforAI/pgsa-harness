# Project Coherence Rules

1. Shared behavior changes must update a contract or create a merge proposal.
2. Session state must be written to `pgsa/state/*.summary.md`.
3. Cross-session uncertainty must be visible in `pgsa/merge_proposals/`.
4. Review gates must record blockers explicitly.
5. Integration readiness must be recorded before final handoff.
6. Important project-state decisions must be appended to the coherence ledger.
7. `export-context` is a convenience packet, not the source of truth.
