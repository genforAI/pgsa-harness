# PGSA Rules

This folder contains lightweight agent-readable boundaries.

Use these files when an agent needs a short policy packet instead of the full
documentation set.

- `claim-boundary.md`: public claim and evidence limits.
- `when-to-use-pgsa.md`: when PGSA is useful and when it is unnecessary.
- `project-coherence-rules.md`: the operational rules that keep sessions
  aligned.
- `pr-gittree-comparison.md`: short boundary between PGSA, PRs, GitTree, and
  worktrees.
- `cli-boundary.md`: short CLI authority boundary.
