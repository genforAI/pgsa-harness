# Claude Code Commands

Use the root `commands/` prompts as slash-command-style workflows for PGSA:

- `pgsa-start-session`
- `pgsa-update-contract`
- `pgsa-merge-propose`
- `pgsa-review-gate`
- `pgsa-integration-check`
- `pgsa-drift-report`

The commands should update repo-local `pgsa/` artifacts rather than relying on
chat history.
